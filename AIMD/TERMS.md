## 🔤 Core Glossary A-Z
[[#^toc-glossary|TOC]]

### Character Spectrum Engine
- **Definition:** The procedural mechanism that converts text characters into corresponding visual wavelengths using regular expressions and a 360-degree linear color loop.
- **Code Implementation Context:** Primarily initialized inside the `injectStyles()` loop and applied inside the `calculateAlphaCharacters()` text validation block.
- **Synonyms / Avoid:** Avoid using "Colorizer", "Rainbow Script", or "Hue Injector".

### Container Isolation
- **Definition:** Scoping a DOM observer loop tightly to an explicit layout view sector to prevent runtime cycles from running on non-essential page updates.
- **Code Implementation Context:** Enforced in `initializeAlphaObserver()` by targeting `.nav-files-container` instead of globally tracing structural modifications via `document.body`.
- **Synonyms / Avoid:** Avoid using "Global Watcher" or "Layout Listener".

### Debounce Loop
- **Definition:** An execution filter that groups multiple consecutive asynchronous callbacks happening inside a narrow time window into a single execution step to protect CPU pipelines.
- **Code Implementation Context:** Declared via the `debouncedCalculate` field wrapper which maps to Obsidian's native `debounce` optimization utility.
- **Synonyms / Avoid:** Avoid using "Throttler", "Sleep Timer", or "Delay Loop".
